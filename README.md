# ORVEX — Huellas Publicidad

Sistema de gestión y seguimiento de órdenes de producción para Huellas Publicidad.

ORVEX centraliza la información de las solicitudes, los diseños gráficos, las aprobaciones, las etapas de producción, las entregas y la trazabilidad de cada orden.

## 💻 Ejecutar el proyecto en local

Necesitas tener Node.js y npm instalados.

1. Clona el repositorio y abre la carpeta del proyecto en Visual Studio Code.
2. Abre una terminal en la carpeta del proyecto.
3. Instala las dependencias:

   ```bash
   npm install
   ```

4. Inicia el servidor de desarrollo:

   ```bash
   npm run dev
   ```

5. Abre en el navegador la dirección local que aparezca en la terminal.
